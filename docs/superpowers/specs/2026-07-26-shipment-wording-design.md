# 출고 처리 용어 정비 설계

## 목표

현재 관리자의 `배송완료` 동작은 WMS 예약 재고를 실제 재고에서 차감하는 출고 처리다.
이번 변경에서는 화면과 안내 문구를 실제 동작에 맞게 `출고 처리`와 `출고 완료`로 정비한다.

## 범위

- 관리자 배송 관리 버튼과 확인·성공·오류 문구를 `출고 처리` 기준으로 변경한다.
- 고객 주문 목록과 상세 화면에서 `COMP`를 `출고 완료`로 표시한다.
- 현재 `DeliveryStatus.READY/COMP`, `completeDelivery()` 및
  `/admin/orders/complete-delivery` 계약은 호환성을 위해 유지한다.
- WMS의 예약 해제와 실재고 차감 시점은 변경하지 않는다.
- 변경된 사용자 문구를 MVC 테스트로 검증하고 기존 서비스 동작 테스트를 유지한다.

## 고도화 전략

실제 배송 추적이 필요해지면 현재 `COMP`의 의미를 출고 완료로 명확히 하고,
배송 완료 상태를 별도로 추가한다.

1. 배송 상태를 최소 `READY -> SHIPPED -> DELIVERED`로 분리한다.
2. OMS 관리자는 출고 요청 또는 출고 확인까지만 담당한다.
3. `DELIVERED` 전이는 택배사 이벤트, WMS/TMS 콜백 또는 별도 관리자 권한 중
   실제 연동 주체가 정해진 뒤 도입한다.
4. 상태 전이의 멱등성, 순서 역전, 콜백 재시도와 고객 노출 문구를 함께 설계한다.

이번 변경에는 위 상태와 연동을 구현하지 않는다.
