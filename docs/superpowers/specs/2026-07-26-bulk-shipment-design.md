# 선택 출고 처리 설계

## 목표

OMS 배송 관리 화면에서 출고 가능한 주문을 여러 건 선택해 한 번에 처리한다.
WMS에는 기존 단건 출고 API를 주문별로 호출하며 새 API를 추가하지 않는다.

## 화면

- `ORDER + READY` 주문에만 선택 체크박스를 표시한다.
- 헤더 체크박스로 현재 목록의 출고 가능 주문을 전체 선택한다.
- `선택 출고 처리` 버튼은 선택된 주문이 없으면 비활성화한다.
- 실행 전 선택 건수를 포함한 확인 창을 표시한다.

## 처리

- `POST /admin/orders/complete-deliveries`가 `orderIds` 목록을 받는다.
- 빈 목록은 처리하지 않고 선택 안내를 표시한다.
- 중복 주문 ID는 한 번만 처리한다.
- 컨트롤러가 기존 `OrderService.completeDelivery(orderId)`를 주문별로 호출한다.
  각 호출은 기존 서비스 트랜잭션에서 독립적으로 커밋 또는 롤백된다.
- 상태 오류, 없는 주문, WMS REST 오류는 해당 주문만 실패 처리하고 다음 주문을 계속한다.
- 완료 후 `성공 N건 / 실패 N건` 결과를 표시한다.

## 제외 범위

- WMS 벌크 출고 API
- 비동기 처리와 작업 큐
- 실패 주문 자동 재시도

처리량이나 호출 지연이 실제 문제가 될 때만 위 항목을 추가한다.
